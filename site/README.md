# Сайт «Славодолья»

Статический сайт, работает без сервера и сборки. Чтобы посмотреть, откройте `index.html` двойным щелчком.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная: развилка «пекарня / кафе», три вида заказа |
| `bakery.html` | Пекарня и доставка: каталог, корзина, оформление |
| `cafe.html` | Кафе: адрес, часы, маршрут (без меню и без заказа) |
| `lunch.html` | Обеды для организаций: условия, документы, заявка |
| `pies.html` | Пироги на заказ: начинка → вес → дата → заявка |
| `contacts.html` | Адреса, телефоны, реквизиты |
| `about.html` | О «Славодолье» |
| `privacy.html` | Политика конфиденциальности (текст даст юрист) |
| **`config.js`** | **Адреса, телефоны, часы, условия доставки, пироги, реквизиты — правьте здесь** |
| **`menu.js`** | **Каталог пекарни: позиции, состав, вес, цены — правьте здесь** |
| `script.js` | Логика: корзина, формы, проверки (обычно трогать не нужно) |
| `styles.css` | Оформление в цветах логобука (обычно трогать не нужно) |
| `assets/` | Логотип, знак, паттерн из птиц |

## Как поменять данные

- Телефон, адрес, часы: откройте `config.js` в Блокноте, впишите значение между кавычками `''`, сохраните. Сайт сам подставит его на все страницы.
- Цена или состав: `menu.js`, поле `price: null` → `price: 190`.
- Пока значение пустое, на сайте видна заглушка `[уточнить]`.

## Что пока не работает

- Заявки не отправляются: гость видит «Спасибо», но заказ никуда не уходит. Место для отправки — функция `sendRequest` в `script.js`.
- Карты, настоящие фото, текст политики и перевод на башкирский — ждут данных.
